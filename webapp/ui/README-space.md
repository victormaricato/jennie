# JENNIE

Free web tool for missense variant mechanism prediction (loss-of-function /
gain-of-function / neutral) using a supervised ESM-2 classifier trained on the
[GLOF benchmark](https://www.biorxiv.org/content/10.64898/2026.06.05.729843v1).

Static front end (Next.js export); model execution is the companion Space
[`victormaricato/jennie-api`](https://huggingface.co/spaces/victormaricato/jennie-api).
Source: <https://github.com/victormaricato/jennie>.
